# center-pay

지대청구 납부금액 엑셀(지난달·이번달 2개)을 올리면 센터별 이번달 납부금액(「지대청구 납부금액」 시트 K열)과
전월 대비 차이(「통합청구(본사유치환불 반영)」 시트 미수계 비교, 항목별 증감)를 조회하는 내부 공유용 웹앱.

- 엑셀은 브라우저에서 파싱하고, 파싱 결과(JSON)만 `/api/data`로 비공개 Vercel Blob에 저장
- 새 파일을 올리기 전까지 모든 사용자가 같은 데이터를 봄 (파일 1개만 올리면 저장된 이번달을 지난달로 사용)
- 지사별 / 담당별 / 센터별 탭, 센터 검색 시 해당 센터 상세만 표시
